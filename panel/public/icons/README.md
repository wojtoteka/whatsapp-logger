# Material Symbols

Te ikony pochodzą z oficjalnego repozytorium
[`google/material-design-icons`](https://github.com/google/material-design-icons),
z wariantu `materialsymbolsoutlined` w rozmiarze 24 px:

- `logout`
- `attach_file`
- `delete`
- `forward`
- `arrow_back`
- `arrow_forward`

Material Symbols są udostępniane przez Google na licencji Apache License 2.0.
